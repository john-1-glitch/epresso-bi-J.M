# Project Reflection

Hayden and I originally planned to build this project as a team, but we could not find a clean way to split and coordinate the work across a single repository. Because I wanted to understand how the whole system worked rather than just handing off pieces, we decided to each build and deploy our own application. I used Claude and Gemini as my AI development partners to build the app step by step, and I connected Gemini as the live language model inside the analytical assistant.

My biggest challenge at the start was understanding how the folders and files in a Python project work together. To keep it organized, `data/raw/` holds the original Access, CSV, and Excel files, `analytics.py` calculates all the numbers, `agent.py` connects the Gemini assistant, `streamlit_app.py` runs the dashboard, and `docs/` and `tests/` store the documentation and checks. On the analytical side, I realized there was a real risk that joining the tables the wrong way could duplicate rows and throw off revenue or survey averages, and AI was really helpful in setting up the right joins so the 105-row survey table stayed separate from the 25,200 sales rows and the $42,174,440 total matched Power BI.

On the technical side, the hardest part was the AI agent part. I ran into a couple of issues like fixing a Gemini timeout issue so the agent answered in about two seconds, plus adding a rules fallback in case the free API quota runs out. Once the app was running, the $1,000 test was pretty easy: I added $1,000 to one row in the sales CSV, uploaded it, and watched total and Website revenue go up by $1,000.

AI wrote the code and helped me push the project and data onto GitHub and Streamlit. My role was guiding the design, checking the results against Power BI, testing the agent, and making sure it refused profit questions. I trust this app for revenue reporting, but I would not use it alone to close a store without cost or margin data.
